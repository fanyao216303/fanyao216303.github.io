Hero 区是「拼贴杂志风」，需要两张照片配合：

  portrait.jpg     —— 主图（更大、稍微逆旋转、占据左上）
  portrait-2.jpg   —— 副图（小、顺旋转、放在右下，覆盖主图一角）

把你的两张照片重命名为以上文件名后放到这个文件夹下即可。

推荐：
- 都用竖版照片
- 主图建议比例 4:5（如 1200×1500）
- 副图建议比例 3:4（如 900×1200）
- 主图选「正面 / 表情更稳」的，副图选「场景化 / 状态更松」的，对比反差更有杂志感
- 文件大小都建议 ≤ 800 KB，太大会拖慢加载（用 https://tinyjpg.com 压缩）

如果你只想放一张照片：
- 只放 portrait.jpg 即可
- portrait-2.jpg 没找到时会自动显示一个虚线占位框（带"02"标记），不影响其它内容
- 想彻底隐藏副图，可在 styles/components.css 里把 .collage-photo--sub 的 display 改成 none

如果想换文件名，去 index.html 里搜索 "portrait" 改 src 即可。
